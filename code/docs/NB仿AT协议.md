# NB 协议

## 接口与帧格式

- 接口：UART5，TX=PC12，RX=PD2；波特率 1,000,000，8N1。
- 接收：DMA1_CHANNEL2 + USART IDLE 中断；发送：阻塞式 `printf`/`usrDebugWrite`。
- 本协议是文本行协议，不是 Modbus，也不带校验和或二进制帧头。
- 命令格式：`NB+键=值\n`。每条命令以单个 `LF`（`\n`）或 `CR`（`\r`）结束。
- `NB`、键名和命令值比较时不区分大小写；前缀中的 `+` 必须存在。`=` 两侧和逗号分隔字段首尾的空格、制表符会被去除。
- 一条命令可以跨多个 DMA 空闲帧接收；DMA 空闲帧边界不是命令结束符。
- 每行最多 63 个非换行字符。超长行会被丢弃，直到下一个换行符，并返回 `NB+ERR,line-overflow`。
- 建议串口工具只发送单个 `LF` 或单个 `CR` 作为行结束符。当前解析器会把 `CRLF` 当成两个结束符处理：命令执行后还会对空行返回 `NB+ERR,empty`。

`USRDEBUG_AT_ENABLE` 当前为 `1`。如果编译时将其设为 `0`，接收帧会被丢弃，AT 命令不再解析。

## 回包约定

执行类命令成功时通常返回 `NB+命令,OK\r\n`。查询命令直接返回数据行，不额外附加 `OK`。解析或参数错误返回：

```text
NB+ERR,<原因>
```

数字参数使用十进制。电流幅值会限幅到 `0~100`，RGB 分量会限幅到 `0~255`，泵速度会限幅到 `-100~100`。超过这些范围的数值不会报错，而是按边界值执行。电机 RPM 参数没有在 AT 解析层做范围检查，使用前应遵守对应电机驱动的安全范围。

## 命令清单

### 28 步进电机与阀门


| 命令                           | 行为或回包                                                  |
| ------------------------------ | ----------------------------------------------------------- |
| `NB+moter28=up`                | 正转，回`NB+moter28=up,OK`                                  |
| `NB+moter28=down`              | 反转，回`NB+moter28=down,OK`                                |
| `NB+moter28=stop`              | 停止，回`NB+moter28=stop,OK`                                |
| `NB+moter28=turn`              | 查询累计步数：`NB+moter28=turn,<步数>`；一圈为 4096 步      |
| `NB+moter28=pos`               | 查询阀门软件到位标志：`NB+moter28=pos,on=<0或1>,off=<0或1>` |
| `NB+valve=on` / `NB+valve=off` | 阀门开 / 关，成功回显对应命令并带`,OK`                      |

### 57 步进电机


| 命令                     | 行为或回包                                                      |
| ------------------------ | --------------------------------------------------------------- |
| `NB+m57=run,<rpm>,<amp>` | 运行；`amp` 为 `0~100`，成功回 `NB+m57=run,OK`                  |
| `NB+m57=run,<rpm>,auto`  | 按 `SP_57_8412_AmpTable` 查表运行（幅值随转速自动取值），回 `NB+m57=run,auto` |
| `NB+m57=stop`            | 停止，回`NB+m57=stop,OK`                                        |
| `NB+m57=amp,<amp>`       | 设置电流幅值，回`NB+m57=amp,OK`                                 |
| `NB+m57=info`            | 查询：`NB+m57=info,pos=<位置>,ang=<角度>,rpm=<转速>,amp=<幅值>` |
| `NB+m57=watch,on`        | 打开标定周期打印（用当前周期），回 `NB+m57=watch,on,<周期ms>`   |
| `NB+m57=watch,off`       | 关闭标定周期打印，回`NB+m57=watch,off`                          |
| `NB+m57=watch,<周期ms>`  | 打开并设置周期，范围`10~1000`（默认 50），回 `NB+m57=watch,on,<周期ms>` |
| `NB+m57=sweep,<rpm>,<加速ms>,<保持ms>,<循环次数>` | 标定自动往返扫描，回 `NB+m57=sweep,on,<rpm>,<加速ms>,<保持ms>,<循环次数>` |
| `NB+m57=run/sweep,blocked,...` | 该方向已到限位，启动被拒绝，回 `NB+m57=run,blocked,high|low` / `NB+m57=sweep,blocked,high|low` |
| `NB+m57=sweep,abort,...`   | 扫描途中撞到限位，已停机并中止，回 `NB+m57=sweep,abort,high` 或 `...,abort,low` |

> `NB+m57=sweep` 每轮时序：静止起步 → S 曲线加速到 `<rpm>` → 保持 `<保持ms>` →
> 硬停（切电流） → 保持 `<保持ms>` → 下一轮。`<循环次数>` 为 `0` 表示无限循环，
> 直到收到 `NB+m57=stop`（`stop` 也会中止扫描）。参数范围：`<加速ms>` `500~30000`，
> `<保持ms>` `100~60000`，`<rpm>` 上限按压制机构机械限制钳到 `3500`（350RPM）。
>
> `<rpm>` 正=下行，负=上行。**限位保护**：低位（压制编码器绝对值到达 `moter57LowEncNum`）只允许上转，
> 高位（PB12）只允许下转；越限方向启动会被直接拒绝（回 `NB+m57=run/sweep,blocked,high|low`），
> 运行中撞到限位立即停机，扫描则回 `NB+m57=sweep,abort,high|low` 并中止。同一条保护也覆盖
> 压制流程的 `pressMoterUp/Down`。
>
> 一轮就覆盖整张 `SP_57_8412_AmpTable`，且每轮都含一次静止起步，用于暴露低档
> 电流不足导致的起步丢步。硬停后电机靠摩擦自由滑行，停止那一刻的 log 会出现
> `denc` 仍在涨而 `pos` 冻结，判读时跳过该行。

> `NB+m57=watch` 每个周期打印一行标定数据：
> `NB+m57=watch,cur=<瞬时指令转速×10>,amp=<当前幅值%>,pos=<指令微步位置>,denc=<本周期压制编码器增量>,adcA/adcB=<绕组原始ADC>,zA/zB=<零点基准>,ia=<绕组A电流A>,ib=<绕组B电流A>`。
> `cur` 是瞬时指令值（`Run` 走 8 秒 S 曲线，途中与目标值不同）；`denc` 是电机实际走过的编码器脉冲数，
> 定速时应保持平稳，掉速或跳变即为该时刻的丢步/抖动，用于定位 `SP_57_8412_AmpTable` 的问题转速区间。
> `ia/ib` 是绕组电流（安培），由 ADC1 注入组在 40kHz 中断里锁存、按零点基准换算，只作趋势判据，
> 不参与控制（幅值始终来自 S 曲线指令转速查表）。
>
> ⚠️ `amp` 参数不能用 `101` 表示自动模式：解析时会把大于 `100` 的值钳到 `100`，
> 反而变成固定满幅值运行并绕过查表，必须写 `auto`。

| `NB+m42=same,<rpm>,<amp>`      | 两台电机同方向运行；成功回`NB+m42=same,OK`                            |

### 抬升机构


| 命令                                        | 行为或回包                                     |
| ------------------------------------------- | ---------------------------------------------- |
| `NB+rise=up` / `NB+rise=down`               | 按默认速度上行 / 下行                          |
| `NB+rise=up,<速度>` / `NB+rise=down,<速度>` | 指定速度上行 / 下行；速度范围`1~6000`          |
| `NB+rise=stop`                              | 停止                                           |
| `NB+rise=pos`                               | 查询高、低位：`NB+rise=pos,high=<值>,low=<值>` |
| `NB+rise=mode,same`                         | 设置两台抬升电机机械同向                       |
| `NB+rise=mode,opposite`                     | 设置两台抬升电机机械反向                       |
| `NB+rise=amp,<幅值>`                        | 左右电机设置相同幅值，范围`0~100`              |
| `NB+rise=amp,<左幅值>,<右幅值>`             | 分别设置左右幅值，范围均为`0~100`              |
| `NB+rise=gear,<档位>`                     | 抬升电流档：`0`=低档（普通上/下行、手动点动、开机自检），其它=高档（压制流程带载）；只选档位，幅值数值见下位机 `moter42.c`，回 `NB+rise=gear,gear=<0/1>,ampL=<%>,ampR=<%>` |
| `NB+rise=seg,<编码器计数>`              | 触发一次"下降一段"：从高位向下走指定编码器计数后零电流自锁；只能从高位启动 |
| `NB+rise=watch,on`                         | 打开标定周期打印（用当前周期），回 `NB+rise=watch,on,<周期ms>` |
| `NB+rise=watch,off`                        | 关闭标定周期打印，回 `NB+rise=watch,off`                       |
| `NB+rise=watch,<周期ms>`                   | 打开并设置周期，范围`10~1000`（默认 50），回 `NB+rise=watch,on,<周期ms>` |
| `NB+rise=zero`                             | 重新标定抬升四路电流零基线（电机须静止），回 `NB+rise=zero,lA=..,lB=..,rA=..,rB=..,OK` |
| `NB+rise=peak[,<窗口ms>]`                  | 窗口内高速采样，回左右电机相电流幅值（A）；窗口默认 300，范围 20~2000 |

动作和设置成功分别返回 `NB+rise=up,OK`、`NB+rise=mode,same`、`NB+rise=amp,OK` 等对应回显。

> `NB+rise=watch` 每个周期打印一行标定数据：
> `NB+rise=watch,cur=<瞬时指令转速×10>,ampL=<左幅值%>,ampR=<右幅值%>,pos=<指令微步位置>,dencL=<左编码器增量>,dencR=<右编码器增量>,ia=<左电机A相电流A>,ib=<左电机B相电流A>,iaR=<右电机A相电流A>,ibR=<右电机B相电流A>,dir=<+1上行/-1下行>,ramp=<1=S曲线进行中>,hi=<高位>,lo=<低位>,encL=<左编码器绝对位置>,encR=<右编码器绝对位置>,dev=<左右绝对位置偏差>`。
> `cur` 是 S 曲线瞬时指令值（抬升走 5 秒 S 曲线，途中与目标值不同）；`dencL/dencR` 是两侧本周期实际
> 走过的编码器脉冲数，正常时两侧应同步平稳，一侧掉速或两侧分叉即为该时刻的丢步/抖动，用于定位
> `SP_42_Left/RightAmpTable` 的问题转速区间。`dev` 为两侧绝对位置之差，同向模式用来看左右是否
> 跟得上、反向模式应恒定不变；`hi/lo` 用来确认上行到高位、下行到低位时停机逻辑是否按预期触发；
> `ramp` 看 S 曲线是否走完。`ia/ib/iaR/ibR` 来自 TMUX1308 D1，每 20ms 刷新一次，只作趋势判据
> （不具备 57 的 40kHz 波形分辨率）；已减去 `NB+rise=zero` 标定的零基线，为**有符号**绕组电流。
>
> `NB+rise=peak` 在窗口内高速循环采样多个电周期取峰，回包：
> `NB+rise=peak,win=<窗口ms>,iaL=<左A>,ibL=<左B>,iaR=<右A>,ibR=<右B>`,ampL=<左电机幅值A=max(左A,左B)>,ampR=<右电机幅值A>,dev=<左右幅值偏差%>`
> （单位均为 A）。要比较两台电机电流是否一致，看 `ampL` 与 `ampR`。该命令会占用 TMUX1308
> 地址线并阻塞调试任务约一个窗口时长（默认 300ms），期间 20ms 传感器快照暂停刷新。

### 泵


| 命令                   | 行为       |
| ---------------------- | ---------- |
| `NB+pump=water,<速度>` | 控制清水泵 |
| `NB+pump=brine,<速度>` | 控制点卤泵 |
| `NB+pump=hose,<速度>`  | 控制蠕动泵 |
| `NB+pump=off`          | 停止三台泵 |

速度范围为 `-100~100`，负数表示反向，`0` 停止对应泵。成功回显泵名称并带 `,OK`，例如 `NB+pump=water,OK`。

### 泵短命令别名（与 cbt7 工程兼容）

除 `NB+pump=...` 外，另支持一组无前缀单字符短命令，与上面共用同一 UART5 指令行，互不影响：


| 命令      | 行为                                        |
| --------- | ------------------------------------------- |
| `W<档位>` | 清水泵，档位 `1~10` → `10%~100%`；`W0` 停止 |
| `H<档位>` | 蠕动泵，档位 `1~10` → `10%~100%`；`H0` 停止 |
| `B<档位>` | 点卤泵，档位 `1~10` → `10%~100%`；`B0` 停止 |
| `S`       | 停止三台泵                                  |

- 大小写不敏感；不写 `NB+`、不写 `=`，直接"字母＋档位"，例如 `W8`、`H5`、`B10`、`S`。
- 清水泵/点卤泵速度走 0.5s S 曲线，蠕动泵沿用 main 线性斜坡；短命令只给正速度，反向请用 `NB+pump=hose,<负值>`。
- 成功回 `NB+OK,<命令>`（如 `NB+OK,W8`）；档位大于 `10` 或数字超过两位回 `NB+ERR,short-gear`。
- 只有"字母＋纯档位数字"或单独的 `S` 会被当作短命令；其余仍走 `NB+` 解析。

### Modbus 统计


| 命令          | 行为                                           |
| ------------- | ---------------------------------------------- |
| `NB+stat=on`  | 打开周期统计；立即打印一次，并每 10 秒打印一次 |
| `NB+stat=off` | 关闭周期打印                                   |
| `NB+stat=now` | 立即打印一次                                   |

统计行格式：

```text
NB+stat,rx=<有效请求帧>,reply=<应答帧>,crcErr=<CRC错误数>,frameErr=<帧错误数>,qOvf=<接收队列溢出数>
```

`on`、`off`、`now` 命令还会返回相应的 `NB+stat=...,OK`。

## 常见错误原因

错误统一返回 `NB+ERR,<原因>`。可能的原因包括：


| 原因                                | 含义                                                  |
| ----------------------------------- | ----------------------------------------------------- |
| `empty`                             | 收到空行（例如使用 CRLF 时多出的第二个结束符）        |
| `prefix`                            | 命令没有`NB+` 前缀                                    |
| `no-eq` / `no-key` / `no-val`       | 缺少等号、键为空或值为空                              |
| `line-overflow`                     | 行长度超过缓冲区上限                                  |
| `short-gear`                        | 泵短命令档位非法（大于 `10` 或数字超过两位）          |
| `key`                               | 不支持的命令键                                        |
| `*-val`、`*-arg`、`*-speed`、`amp*` | 命令值或参数格式不符合要求；具体后缀对应出错命令/参数 |

电机、阀门、泵和复位使能命令会实际驱动硬件。调试前请确认机械结构安全，并先使用停止命令结束动作。
