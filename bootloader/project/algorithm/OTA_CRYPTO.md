# OTA SHA-256 校验

当前不使用数字签名或公私钥。设备端和上位机对完整原始 BIN 计算 SHA-256。

镜像布局保持不变：

- 偏移0：1KB版本区域，UTF-8版本号后填零。
- 偏移1024：原1KB签名区域改为SHA-256区域，前32字节保存摘要，剩余992字节填零。
- 偏移2048：完整原始BIN，不修改其内容。

`APP1DATA2` / `APP2DATA2` 地址不变，存放对应固件的32字节摘要。
`verify_firmware()` 从 `MSPx_ADDR` 开始直接读取原始BIN长度的数据，
计算SHA-256后比较该区域前32字节；相等返回1，否则返回0。
不改变包级CRC、写Flash及分区切换逻辑。

上位机 `package(raw, version)` 自动生成摘要，无需密钥文件。
旧签名镜像不兼容，必须重新生成。

算法目录只保留SHA-256及本说明；旧BLAKE3、Ed25519、c25519、Monocypher
及SHA-512源码已清理。无需安装Python cryptography。
SHA-256只核对完整性，不提供固件来源认证。
